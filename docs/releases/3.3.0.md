# dlsite-manager 3.3.0

Stable release with library pagination, two-factor login support, Linux AppImage
distribution, and safer download replacement and recovery.

## Added

- Browse libraries beyond the first 100 products with page navigation, visible ranges,
  and page resets when filters or sorting change. Bulk downloads cover all matches.
- TOTP two-factor login prompts for account sync and downloads, with cancellation and
  remembered-session reuse for accounts that save their password.
- Linux x86_64 AppImage downloads and in-app updates, alongside macOS Apple Silicon
  DMG and Windows x64 MSI/NSIS installers.

## Fixed

- Preserve installed content when replacement downloads fail or are cancelled, and
  retain installation recovery and staging cleanup across restarts.
- Serialize account authentication and changes, cancel pending authentication promptly,
  and prevent queued account saves from undoing a disabled account's state.
- Prevent stale library/detail/filter responses and two-factor prompts from overwriting
  current UI state. Restore filter button styling and prevent clipped product credits.
- Build AppImages with Tauri CLI 2.12.0, which stops bundling xdg-open and xdg-utils
  and uses the desktop host's utilities instead
  ([upstream fix](https://github.com/tauri-apps/tauri/pull/15804)). This addresses a
  candidate cause of folder-opening failures; resolution of
  [#47](https://github.com/AcrylicShrimp/dlsite-manager/issues/47) still needs Linux
  desktop confirmation. The bundled Wayland-library workaround is retained.

## Maintenance

- Refresh Rust/frontend dependencies and build tooling, including SQLx 0.9, ZIP 8,
  Vite 8, and the TypeScript 7 checker.
- Split the frontend into reusable views, dialogs, and controllers with a Storybook
  workbench, automated CI, and lifecycle regression tests.
- Add a download-recovery database migration. Existing migrations remain unchanged;
  an automated v3.2.2 upgrade regression checks representative data retention.

## Known limitations

- Real-account 2FA/non-2FA login, DLsite reCAPTCHA behavior, and interactive native
  installation/update acceptance remain unverified. Automated tests and successful
  packaging do not establish those results.
- Linux folder opening may still be affected by inherited AppImage environment
  variables. Please report any remaining failures with this build in #47.
- macOS bundles use ad-hoc signing without Apple notarization. Updater signatures
  and SHA-256 checksums are provided separately from operating-system code signing.

## Validation

macOS, Windows, and Linux release builds passed in
[run 36319639931](https://github.com/AcrylicShrimp/dlsite-manager/actions/runs/36319639931).
All 13 release assets were downloaded; all SHA-256 checksums, four updater signatures
(including their signed 3.3.0 version metadata), and all three updater manifest entries
were verified. Local automated checks and GitHub CI passed. Interactive installation,
updates, live login, and Linux desktop folder opening remain unverified.

## Release decision

3.3.0 is a minor release because it adds capabilities without an intentional breaking
desktop change. On 2026-09-27 the maintainer explicitly requested stable publication;
this supersedes the earlier RC-only publication hold, without marking the outstanding
manual acceptance checks as passed.
