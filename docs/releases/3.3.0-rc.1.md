# dlsite-manager 3.3.0-rc.1

First release candidate for 3.3.0, based on changes since v3.2.2. This is a prerelease
for validation; the stable update channel continues to serve the latest stable release.

## Added

- Browse libraries beyond the first 100 products with page navigation, visible ranges,
  and page resets when filters or sorting change. Bulk downloads still cover all matches.
- TOTP two-factor login prompts for account sync and downloads, with cancellation and
  remembered-session reuse for accounts that save their password. Live DLsite login
  acceptance, including reCAPTCHA behavior, still needs verification.
- Linux x86_64 AppImage release builds and updater artifacts, including a packaging fix
  for bundled Wayland library conflicts.

## Fixed

- Preserve installed content when replacement downloads fail or are cancelled; persist
  installation recovery state and track restored staging through restart and deletion.
- Serialize account authentication and changes, cancel pending authentication promptly,
  and prevent queued account saves from undoing a disabled account's state.
- Prevent stale library/detail/filter responses and two-factor prompts from overwriting
  current UI state. Restore filter button styling and prevent clipped product credits.

## Maintenance

- Split the frontend into reusable views, dialogs, and controllers with a Storybook workbench.
- Refresh Rust/frontend dependencies and build tooling, including stable SQLx 0.9, ZIP 8,
  Vite 8, and the TypeScript 7 checker; add automated CI and lifecycle regression tests.
- Add one database migration for download recovery. Existing migration files remain
  unchanged; a file-backed v3.2.2 upgrade regression verifies representative data retention.

## Known issues and remaining validation

- Real-account 2FA/non-2FA login, cancellation, remembered-session behavior, and native
  install/update acceptance remain pending. Automated tests do not establish live login.
- AppImage folder opening is still reported broken in
  [#47](https://github.com/AcrylicShrimp/dlsite-manager/issues/47); this candidate does not
  include a dedicated fix. Linux desktop acceptance remains pending.
- macOS bundles use ad-hoc signing, without Apple notarization. Updater signatures are
  separate from operating-system code signing.
- The development toolchain retains a low-severity transitive `cookie` advisory; the
  dependency refresh's production-only audit reported zero advisories.

## Version decision

Target 3.3.0 is a minor release because pagination, TOTP login, and Linux distribution
add user-visible capabilities. The upgrade path preserves existing data, and no intentional
breaking desktop behavior was identified. Dependency major-version changes alone do not
require a major app version. Use `-rc.1` while native/live acceptance is incomplete.

Release validation and remaining gates are tracked in
