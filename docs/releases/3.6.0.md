# dlsite-manager 3.6.0

Choose which language to use for work titles and maker names, while searching
your collection across all available translations.

## Added

- Settings → Names lets you reorder a shared language preference for work titles
  and maker names. The order is saved between app launches and applies to Library
  lists, details, sorting and maker filter labels.
- The language list includes defaults and every language found in cached names.
  Complete bundled Unicode CLDR English labels help identify each language while
  preserving its original code; unfamiliar codes remain available to reorder.

## Changed

- Library search checks all cached title and maker translations, including those
  that are not currently displayed.
- Maker filters keep their selection when the displayed language changes.
- Saving a changed language order refreshes Library and open work details, keeps
  active filters and returns pagination to the first page.

## Database upgrade

- On first launch, an automatic migration makes localized JSON maps the source
  for names and removes the stored selected-title/maker columns. Existing names
  without a usable translation map are retained under the unspecified `und` code.
- Accounts, ownership, tags and download relationships are preserved. After this
  migration, the upgraded database is not compatible with 3.5.0 or older builds.

## Notes

- Linux folder-opening issue [#47](https://github.com/AcrylicShrimp/dlsite-manager/issues/47)
  remains pending an upstream Tauri fix.
- macOS builds use ad-hoc signing without Apple notarization. Release artifacts
  include updater signatures and SHA-256 checksums.
