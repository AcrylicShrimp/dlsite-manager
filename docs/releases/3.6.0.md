# dlsite-manager 3.6.0

You can now choose which language to use for work titles and maker names.

## What's new

- Reorder your preferred languages in **Settings → Names**. The order applies
  to titles and maker names throughout Library.
- Search finds all available title and maker translations, regardless of the
  language currently displayed.
- Maker filters keep their selection when you change the display language.

## Upgrading

The library database is updated automatically on first launch. Existing library
data is preserved, but the updated database cannot be opened with 3.5.0 or older.

## Known issues

- Linux folder-opening issue [#47](https://github.com/AcrylicShrimp/dlsite-manager/issues/47)
  is still awaiting an upstream Tauri fix.
- macOS builds are not notarized by Apple.
