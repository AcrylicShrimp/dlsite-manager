# dlsite-manager 3.5.0

A redesigned workspace for browsing your collection, managing downloads and
accounts, and tracking errors.

## Changed

- A consistent layout across Library, Downloads, Accounts, Activity and Settings,
  with shared page actions, search/filter tools and reload controls.
- Library uses compact cover cards with colored work-type and age badges, plus
  distinct icons for queued, downloading, extracting and locally available works.
  Existing search filters, pagination, metadata and custom tags remain available.
- Work details put key information and actions first, with secondary details in
  expandable sections. Cover previews open in a dialog and support saving images.
- Activity separates work history from application logs. Settings separates
  storage options from About and updates; reverting unsaved settings is now
  labeled Revert changes.
- Long pages use the main content scroll area, with a back-to-top button. The
  sidebar also scrolls in short windows and separates download status from app
  information.

## Fixed

- Error notifications show a readable message and a View in Activity action
  instead of appending a long diagnostic ID. The linked operation view supports
  copying the ID and exporting the relevant records, including clipboard fallback.
- Activity refreshes its logs on entry and when switching to Application logs,
  so failures before a background job starts no longer leave the list stale.
- Improved shared button spacing, focus indicators, dialog layering and narrow
  layouts. Settings now uses the available content width.

## Notes

- Linux folder-opening issue [#47](https://github.com/AcrylicShrimp/dlsite-manager/issues/47)
  remains pending an upstream Tauri fix; this release does not claim to resolve it.
- macOS builds use ad-hoc signing without Apple notarization. Update artifacts
  include updater signatures and SHA-256 checksums.

## Validation

- Main/release CI and all three platform builds passed in
  [release run 36421286251](https://github.com/AcrylicShrimp/dlsite-manager/actions/runs/36421286251).
- All 13 uploaded assets were downloaded and checked: SHA-256 checksums, four
  updater signatures with signed version metadata, and all three manifest entries.
  The macOS app passed strict/deep code-signature verification.
- The release AppImage ran on OrbStack Ubuntu 22.04 with IceWM. Navigation and
  update checking passed. A real validation error opened its correlated Activity
  details, and native export produced a valid ZIP containing only that operation.
- Chromium/WebKit checks covered narrow layouts, shared action callbacks, filters,
  details and diagnostic fallback states. Live account sign-in, native Windows UI
  and installation through the updater were not revalidated in this release check.
